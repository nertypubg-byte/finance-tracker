About the project:

A full-fledged financial tracker for your personal budget with support for importing CSV bank statements.
Features:
1) CSV bank statement import
2) Manual transaction entry with automatic category detection
2) Charts: income/expenses by month, expenses by category
3) Summary cards: income, expenses, balance, savings rate
4) Categories with automatic detection by keywords (food, transportation, shopping)
5) Budget by category with progress bars and overage alerts
6) Financial goals with replenishment and deadlines
7) Filtering by month, category, type, and search
8) Editing categories directly in the transaction list
9) Auto-save to local storage

| Technology | Appointment |
| :--- | :--- |
| **React 18** | UI components |
| **TypeScript 5** | Typing |
| **Recharts 2** | Graphs |
| **Vite 5** | Assembly and dev server |
| **LocalStorage** | Data storage |
| **Web Crypto API** | Used in chainledger |

## How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nertypubg-byte/finance-tracker
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
