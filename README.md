# 💰 Finance Tracker by Kotsovv

A full-fledged financial tracker for your personal budget with support for importing CSV bank statements.

## 🚀 Key Features

### 🏦 Data & Transactions
* **Smart Import** — Support for importing **CSV bank statements** for quick data entry.
* **Auto-Categorization** — Manual transaction entry with automatic detection by keywords (e.g., food, transportation, shopping).
* **Direct Editing** — Modify categories and transactions directly within the list.
* **Auto-Save** — Your data is always safe with automatic saving to **Local Storage**.

### 📊 Analytics & Budgeting
* **Interactive Charts** — Visualize income and expenses by month or category.
* **Summary Cards** — Real-time tracking of your **Balance**, **Income**, **Expenses**, and **Savings Rate**.
* **Budget Planning** — Set budgets by category with visual **progress bars** and overage alerts.
* **Financial Goals** — Track your savings goals with replenishment history and deadlines.

### 🔍 Search & Filters
* **Advanced Filtering** — Quickly find what you need by month, category, type, or custom search queries.

## How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nertypubg-byte/finance-tracker
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
